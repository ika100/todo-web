# todo-web

Web frontend for the todo app

Next.js (App Router) web app generated from the `web-nextjs` template of [`ika100/sdlc-foundry`](https://github.com/ika100/sdlc-foundry).

```bash
devbox shell
devbox run dev        # http://localhost:3000
devbox run quality    # eslint + tsc
devbox run test       # vitest + coverage
devbox run image-build
```

See `CLAUDE.md` for conventions and the full recipe list. Skeleton updates: `/shared:update-service`.
